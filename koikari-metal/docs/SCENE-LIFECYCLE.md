## 问题与处理

新增资源的 `scenario/main/5_3.ks:8` 使用 `SC_SceneStartProcess`，此前没有对应的原生处理器，因此运行时在此阻塞。

已按原宏的普通剧情分支补齐：

- 无参数的场景开始只更新场景标志，不清除既有背景、音乐、立绘或消息框状态。实际追加包中 26 处调用均无参数。
- 提供背景时按原宏的背景切换语义处理；音乐缺省时保留，显式停止时停止；消息框按相应默认样式恢复。
- 普通 `SC_SceneEnd` 只清除场景标志，不擅自跳章、黑场或停止音乐；`SC_EndProcess` 也执行这一步，再沿既有章节表继续。
- 同章后续还会遇到 `whiteout`，现按当前立即转场模型保留它的最终背景，其他图层及音乐不丢失。并未完整还原白闪的原始时长。
- 对于旧版保存的这几条已修复指令的未知指令错误，加载后第一次推进会在**原程序位置重新执行**。必须同时匹配当前指令、位置、行号和原错误，其他未知指令、参数错误、条件错误不会被清除或跳过。

## 如何继续

先按[构建说明](<../BUILD-AND-RUN.md>)从 GitHub 源码构建新版（Rust 1.95.0、macOS / Apple Silicon），仓库不提供预编译程序。完全退出旧游戏窗口后，用 `./target/release/koikari-metal --root "$KOIKARI_GAME_ROOT"` 启动，其中 `KOIKARI_GAME_ROOT` 设为你自有资源目录，例如 `/path/to/owned-game`。F9 读取存档，然后按一次空格/回车或点击推进。如果存档正好停在此次报错位置，会重试该指令，不必手动跳到下一章。

本次没有修改任何原始归档或用户存档，资源模式及默认存档位置也没有变化。
